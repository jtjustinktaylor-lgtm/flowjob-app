# Landing Page — Premium Visual Polish

## ✨ Animations Added

### Scroll-Triggered Reveals
- **Intersection Observer** — Elements animate in as you scroll down
- **Staggered delays** — Feature cards appear one by one (100ms apart)
- **Smooth easing** — `cubic-bezier(0.4, 0, 0.2, 1)` for premium feel

### Hero Section
| Element | Animation |
|---------|-----------|
| Logo | Scale-in (0.6s) with bounce easing |
| Title | Fade-up (0.8s) with 0.3s delay |
| Tagline | Fade-up (0.8s) with 0.4s delay |
| CTA Button | Fade-up + pulse glow every 3s |
| Background | Floating gradient (8s infinite loop) |
| Scroll Arrow | Bouncing indicator at bottom |

### Interactive Effects
- **Logo** — Scales up 5% and rotates -2° on hover, enhanced gold glow

- **Steps** — Slide right 8px on hover with gold background tint
- **Privacy Badges** — Lift 4px with shadow on hover
- **CTA Button** — Shine sweep effect on hover (white gradient)
