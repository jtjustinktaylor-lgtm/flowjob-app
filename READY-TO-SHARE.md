## 💡 Before Sharing: Proton Mail?

**Recommendation:** Share now, set up Proton Mail later.

**Why?**
- App works 100% offline — no email needed for core functionality
- Users can export/backup without email
- Formspree (already integrated) handles form submissions
- You can add Proton Mail anytime without changing the app

**When to set up Proton Mail:**
- If you want a custom email (justin@flowjob.app)
- For professional quote/invoice delivery
- For customer communication
- For business branding

**How to add later:**
1. Create Proton Mail account
2. Add email to Settings page
3. Update quote/invoice templates
4. No code changes needed!
